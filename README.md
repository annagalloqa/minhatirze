# 💉 Minha Tirze

**Seu diário particular de tratamento com tirzepatida.**

> 📱 PWA · offline · dados salvos só no seu celular · iPhone e Android

[![Abrir App](https://img.shields.io/badge/📱-Abrir_App-C4717A?style=for-the-badge)](https://annagalloqa.github.io/minhatirze/)

---

## ✨ Funcionalidades

- 💉 **Registro de aplicações** — data, dose, local no corpo (8 zonas), observações
- 🔄 **Conversor mg → UI** — para frascos de 5mg, 10mg ou 15mg
- 🗓 **Lembretes no Calendário** — iPhone (app Calendário) e Android (Google Calendar)
- 🌡 **Diário de sintomas** — 10 sintomas, notas diárias, histórico
- ⚖️ **Acompanhamento de peso** — meta, gráfico Canvas, barra de progresso
- 🧬 **IMC + Proteína** — calcula IMC e recomendação diária de proteína
- 🗺 **Rodízio inteligente** — sugere a melhor zona para a próxima aplicação
- 🏆 **Conquistas** — 8 badges para desbloquear ao longo do tratamento
- 📸 **Share Card** — gera imagem personalizada do seu progresso
- 📤 **Exportação de dados** — leve seu histórico ao médico
- 🔒 **PIN de 4 dígitos** — seus dados protegidos
- 🌐 **100% offline** — funciona sem internet depois de instalado

---

## 📲 Instalação

### iPhone (Safari)
1. Abra o link no Safari
2. Toque **···** → **Compartilhar** → **Adicionar à Tela de Início**

### Android (Chrome/Brave)
1. Abra o link no navegador
2. Toque **⋮** → **Adicionar à tela inicial** / **Instalar app**
